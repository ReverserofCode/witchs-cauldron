# 팬카페 업데이트 게시 템플릿

아래 템플릿을 복사해 매 업데이트마다 값만 바꿔 사용하세요.

---

## 0) 입력값
- 날짜/시간: `<YYYY-MM-DD HH:mm>`
- 프로젝트명: `<witchs-cauldron>`
- 프로젝트 도메인: `<https://moingfans.com>`
- 배포 버전(커밋): `<sha>`
- 수정/추가 기능 개수: `<N>`

---

## 1) 게시글 제목 템플릿
```text
[업데이트 안내] <YYYY-MM-DD> <핵심 변경 한 줄>
```

예시:
```text
[업데이트 안내] 2026-03-07 클립 수집/반영 안정화
```

---

## 3) 스크린샷
- 기능 1
  - [스크린샷 1] <입력/설정 화면 설명 1줄>
  - [스크린샷 2] <결과/적용 화면 설명 1줄>

  - [스크린샷 1] <입력/설정 화면 설명 1줄>

## 4) 서비스 주소
- 프로젝트 도메인: <https://...>

---

## 3) 스크린샷 첨부 템플릿 (기능당 2장)

파일명 규칙:
```text
fan-update-<YYYYMMDD>-<feature-key>-01-input.png
fan-update-<YYYYMMDD>-<feature-key>-02-result.png
```

예시:
```text
fan-update-20260307-collect-01-input.png
fan-update-20260307-collect-02-result.png
fan-update-20260307-sync-01-input.png
fan-update-20260307-sync-02-result.png
```
