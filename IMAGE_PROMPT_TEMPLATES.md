# IMAGE_PROMPT_TEMPLATES

마녀의 포션 공방용 실전 프롬프트 템플릿 3종입니다.

## 1) 메인 히어로 배너 (웹 메인 상단)

**권장 사이즈**: 1920x1080 (추후 크롭하여 16:9/21:9 대응)

```text
Create a high-quality hero banner for a Korean VTuber fan community website called "마녀의 포션 공방".
Theme: magical potion workshop, cozy fantasy, purple + emerald accent, soft glow particles.
Include clear visual focus area on the left for headline text overlay.
Do not include copyrighted logos or real brand marks.
Style: polished web hero illustration, clean composition, modern, slightly whimsical.
Mood: warm, welcoming, energetic.
Output: 1920x1080, sharp details, no watermark, no text baked into image.
```

**권장 사이즈**: 1280x720

```text

Korean audience friendly style, high contrast focal burst at center, clean edges for text placement.
Color palette: deep violet, neon mint, subtle gold spark accents.

Output: 1280x720, thumbnail-ready, no text, no watermark.
```
